# Мәселені талдау

## Мәселе
Электрондық анықтама көбіне PDF, файл немесе скриншот ретінде жіберіледі. Алушы (жұмыс беруші, банк, оқу орны) оның жалған емес, кері қайтарылмаған және мерзімі өтпегенін тез тексере алмайды. Бір цифрды өзгерту (мысалы, табыс сомасын) өте оңай.

## Шешім
1. Беруші анықтаманың барлық өрісіне **RSA қолтаңбасын** (SHA256withRSA) қояды.
2. Анықтаманың ID, түрі және мерзімі **тізілімге** (SQLite) жазылады. Азаматтың аты-жөні мен ЖСН тізілімде сақталмайды.
3. Тексеруші `.edoc` файлын ашады. Бағдарлама алдымен қолтаңбаны, содан кейін тізілімді, кері қайтаруды және мерзімді тексереді.
4. Беруші қателесіп берілген анықтаманы кері қайтара алады: қолтаңбаның өзін "жоюға" болмайды, сондықтан отзыв тізілімде тұрады.

## Шектеулер
- Нақты eGov-тағы QR-код және иесінің келісімі жоқ, тек файл тексеріледі.
- Сертификаттар тізбегі жоқ, ашық кілт бағдарламаға тікелей берілген.
- Алгоритм RSA (қазақстандық ГОСТ Р 34.10-2015 стандартты JCA-да жоқ).
